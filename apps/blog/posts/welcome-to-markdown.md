# 欢迎使用 Markdown 编辑器

这是一个功能强大的 Markdown 编辑器，支持将 Markdown 文件导入到 Sanity CMS。

## 主要特性

- **实时预览**: 所见即所得
- **语法高亮**: 代码块支持
- **元数据支持**: YAML frontmatter
- **批量导入**: 一键导入多个文件

## 代码示例

\`\`\`typescript
function greet(name: string) {
  console.log(`Hello, ${name}!`);
}

greet("World");
\`\`\`
