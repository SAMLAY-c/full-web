# 模块：内容

## 作用
- 保存站点内容源文件（Markdown/MDX）。

## 内容目录
- 博客文章：`apps/blog/posts/`
  - `apps/blog/posts/welcome-to-markdown.md`
  - `apps/blog/posts/2025-01-28-next-js-best-practices.md`
- 博客内容规范：`apps/blog/MARKDOWN_IMPLEMENTATION.md`
- 博客内容指南：`apps/blog/MARKDOWN_GUIDE.md`
- 博客 MDX 内容：`apps/blog/content/intro.mdx`
- 作品集内容：`apps/portfolio/content/ai-onboarding.mdx`

## 关联模块
- 前端模块负责渲染展示。
- 后端与脚本模块负责导入、发布与查询。
